# Aspectos de Programação das Tarefas OBI

Este arquivo resume, para cada tarefa preparada no projeto, quais ideias de programação a solução envolveu e quais estruturas de dados foram necessárias.

## OBI

- Resolução: soma de pontos por competidor e contagem condicional.
- Estruturas de dados: variáveis escalares; nenhuma estrutura adicional.
- Aspectos de programação: leitura em laço, agregação, comparação com limiar.

## Telefone

- Resolução: mapeamento de letras para dígitos do teclado telefônico.
- Estruturas de dados: StringBuilder.
- Aspectos de programação: processamento de caracteres, regras condicionais.

## Vestibular

- Resolução: comparação posição a posição entre gabarito e respostas.
- Estruturas de dados: strings.
- Aspectos de programação: iterações indexadas, contagem.

## Aviões de papel

- Resolução: verificação de capacidade total de folhas.
- Estruturas de dados: variáveis escalares.
- Aspectos de programação: aritmética básica, condição booleana.

## Número de Envelopes

- Resolução: cálculo do mínimo entre quantidades de rótulos.
- Estruturas de dados: variáveis escalares.
- Aspectos de programação: varredura linear, mínimo acumulado.

## Overflow

- Resolução: avaliação de expressão e comparação com limite.
- Estruturas de dados: variáveis escalares.
- Aspectos de programação: parsing simples, escolha por operador, uso de tipo numérico maior.

## Garçom

- Resolução: soma dos copos quebrados nas bandejas que caem.
- Estruturas de dados: variáveis escalares.
- Aspectos de programação: laço com acumulação e condição.

## Pneu

- Resolução: diferença entre pressão desejada e lida.
- Estruturas de dados: variáveis escalares.
- Aspectos de programação: subtração direta.

## Sedex

- Resolução: verificação se diâmetro cabe em todas as dimensões da caixa.
- Estruturas de dados: variáveis escalares.
- Aspectos de programação: comparações múltiplas.

## Campo Minado

- Resolução: contagem local de minas na célula e vizinhas imediatas.
- Estruturas de dados: array de inteiros.
- Aspectos de programação: tratamento de borda, vizinhança linear.

## Corrida

- Resolução: cálculo do menor tempo total entre competidores.
- Estruturas de dados: variáveis escalares.
- Aspectos de programação: somatório por linha, rastreamento de mínimo e índice.

## Transporte de Contêineres

- Resolução: produto das quantidades que cabem em largura, comprimento e altura.
- Estruturas de dados: variáveis escalares.
- Aspectos de programação: divisão inteira, multiplicação.

## Busca na Internet

- Resolução: aplicação direta da relação entre cliques dos links.
- Estruturas de dados: variáveis escalares.
- Aspectos de programação: modelagem algébrica simples.

## Campeonato

- Resolução: comparação lexicográfica por pontos e saldo de gols.
- Estruturas de dados: variáveis escalares.
- Aspectos de programação: pontuação derivada, desempate.

## Desafio do Maior Número

- Resolução: leitura até sentinela zero e manutenção do maior valor.
- Estruturas de dados: variáveis escalares.
- Aspectos de programação: laço com sentinela, máximo acumulado.

## Saldo do Vovô

- Resolução: simulação das movimentações e registro do menor saldo.
- Estruturas de dados: variáveis escalares.
- Aspectos de programação: acumulador, mínimo prefixo.

## Tomadas

- Resolução: soma das tomadas disponíveis descontando as conexões entre réguas.
- Estruturas de dados: variáveis escalares.
- Aspectos de programação: aritmética simples.

## Fila

- Resolução: remoção lógica dos identificadores que saíram da fila.
- Estruturas de dados: array de inteiros, HashSet.
- Aspectos de programação: filtragem, teste de pertinência.

## Flíper

- Resolução: determinação do caminho da bolinha a partir das duas portinhas.
- Estruturas de dados: variáveis escalares.
- Aspectos de programação: árvore de decisão.

## Gangorra

- Resolução: comparação de torques dos dois lados.
- Estruturas de dados: variáveis escalares.
- Aspectos de programação: produto, comparação ternária.

## Fita Colorida

- Resolução: distância ao zero mais próximo com duas passadas.
- Estruturas de dados: array de inteiros.
- Aspectos de programação: programação por varredura esquerda-direita e direita-esquerda.

## Móbile

- Resolução: checagem das três equações de equilíbrio.
- Estruturas de dados: variáveis escalares.
- Aspectos de programação: modelagem com igualdade entre expressões.

## Prêmio do Milhão

- Resolução: acumulação diária até atingir um milhão.
- Estruturas de dados: variáveis escalares.
- Aspectos de programação: prefix sum com parada antecipada.

## Jogo de par ou ímpar

- Resolução: decisão do vencedor a partir da paridade da soma.
- Estruturas de dados: variáveis escalares.
- Aspectos de programação: módulo, lógica condicional.

## Lâmpadas

- Resolução: simulação dos estados das lâmpadas após sequência de interruptores.
- Estruturas de dados: variáveis escalares.
- Aspectos de programação: estado binário, toggling.

## Plantação de Morangos

- Resolução: comparação entre áreas de dois retângulos.
- Estruturas de dados: variáveis escalares.
- Aspectos de programação: produto e máximo.

## Bondinho

- Resolução: verificação de lotação máxima da cabine.
- Estruturas de dados: variáveis escalares.
- Aspectos de programação: soma e comparação.

## Drone de Entrega

- Resolução: checagem se alguma face da caixa passa pela janela.
- Estruturas de dados: arrays pequenos, Arrays.sort.
- Aspectos de programação: ordenação de dimensões, comparação de pares.

## Basquete de robôs

- Resolução: classificação por faixa de distância.
- Estruturas de dados: variáveis escalares.
- Aspectos de programação: intervalos e decisão.

## Álbum da copa

- Resolução: contagem de figurinhas distintas já obtidas.
- Estruturas de dados: array booleano.
- Aspectos de programação: deduplicação simples, contagem de distintos.

## A idade de Dona Mônica

- Resolução: reconstrução da terceira idade e escolha da maior.
- Estruturas de dados: variáveis escalares.
- Aspectos de programação: equação simples, máximo.

## Dominó

- Resolução: aplicação direta da fórmula fechada do número de peças.
- Estruturas de dados: variáveis escalares.
- Aspectos de programação: fórmula matemática.

## Sequência Secreta

- Resolução: contagem de blocos consecutivos distintos na sequência.
- Estruturas de dados: variáveis escalares.
- Aspectos de programação: compressão implícita de sequência.

## Camisetas da Olimpíada

- Resolução: contagem de demanda por tamanho e comparação com estoque.
- Estruturas de dados: variáveis escalares.
- Aspectos de programação: frequência simples, validação de capacidade.

## Divisão do Tesouro

- Resolução: cálculo da divisão igualitária com capitão recebendo o dobro.
- Estruturas de dados: variáveis escalares.
- Aspectos de programação: modelagem algébrica, divisão inteira exata.

## Entrega de Caixas

- Resolução: determinação do menor número de viagens conforme encaixes possíveis.
- Estruturas de dados: variáveis escalares.
- Aspectos de programação: análise de casos, desigualdades.

## Escher

- Resolução: verificação de soma constante entre elementos simétricos.
- Estruturas de dados: array de inteiros.
- Aspectos de programação: dois ponteiros implícitos, simetria.

## Piloto Automático

- Resolução: comparação das distâncias do carro central aos extremos.
- Estruturas de dados: variáveis escalares.
- Aspectos de programação: diferença entre posições, comparação.

## Relógio de Atleta

- Resolução: classificação do estado do atleta por regras compostas.
- Estruturas de dados: variáveis escalares.
- Aspectos de programação: ordem de precedência entre condições.

## Idade de Camila

- Resolução: obtenção da mediana entre três idades.
- Estruturas de dados: array pequeno, Arrays.sort.
- Aspectos de programação: ordenação e seleção do elemento central.

## Plano de Internet

- Resolução: saldo acumulado de franquia mês a mês.
- Estruturas de dados: variáveis escalares.
- Aspectos de programação: soma acumulada, expressão final.

## Torneio de tênis

- Resolução: contagem de vitórias e mapeamento para grupo.
- Estruturas de dados: variáveis escalares.
- Aspectos de programação: contagem categórica, intervalos.
